# EmpowerOS

> AI Employee Defense Command Center — Leveling workplace information asymmetry.

EmpowerOS protects employees throughout their entire employment lifecycle:
1. **Stage 1 (Before Signing)**: Offer Letter Scanner, Contract Redline Engine, 24/7 IP Trap Detection, Exhibit A Rider Generator.
2. **Stage 2 (While Working)**: Policy Oracle AI Chat with verified chapter/section citations, Unclaimed Wellness & Learning Stipend Discovery.
3. **Stage 3 (Terminated)**: Severance Defense, 90-Day Option Cliff Audit, Interactive Financial Runway Calculator, 1-Click Counter Email Generator.

## Getting Started

First, install dependencies:
```bash
npm install
```

Configure your environment variables in `.env.local`:
```env
GEMINI_API_KEY=your_gemini_api_key
```

Run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
